Research

Research interests

我更关心能够形成长期统一智能系统的问题，而不是孤立地优化某一个任务指标。

01

World Models

研究智能体如何维护动态环境的内部表征，并区分观察者运动、 表征变化与真实世界变化。

02

JEPA & Representation Learning

关注预测式表征学习、latent dynamics、representation geometry， 以及不同几何结构对预测和规划的影响。

03

Embodied Intelligence

研究感知、记忆、技能、工具与控制系统如何组合， 形成能够在真实环境中持续运行的具身智能体。

04

Curiosity & Autonomous Learning

探索如何让智能体主动选择值得学习的经验， 以 learnability、uncertainty 与 information gain 驱动长期探索。

Projects

Selected projects

一些围绕具身智能、世界模型和自主学习展开的长期项目。

PROJECT / 01

Explorer

一个面向移动具身智能体的持续世界模型系统。 Explorer 试图通过 structural map、object registry、 memory、transport 与 dynamics 将观察组织成稳定的世界知识。

World Model · Memory · Robotics
PROJECT / 02

Curiosity Agent

研究智能体如何在开放环境中自主提出探索目标， 判断哪些经验具有学习价值，并将交互轨迹逐渐抽象为长期知识和技能。

Curiosity · RL · Active Learning
PROJECT / 03

JEPA Representation Geometry

比较 Gaussian、subspace、sparse 与 topology-aware latent geometry， 分析其对一步预测、长程 rollout 与 planning regret 的影响。

JEPA · Representation · Planning
PROJECT / 04

UAV VLA + JEPA

探索使用 action-conditioned predictive representations 增强无人机 VLA 的高速物理任务能力， 包括轨迹预测、释放事件建模与真实机器人实验。

VLA · UAV · Predictive Control

About me

我是一名人工智能专业学生，目前主要学习并研究具身智能、世界模型、 表征学习和自主智能体。

相比单纯扩大模型规模，我更感兴趣的是智能系统内部应当具有怎样的结构： 什么应该被记忆，什么应该被预测，什么应该交给工具， 什么需要通过主动交互重新观察，以及一个智能体如何把大量经验逐渐组织成 可复用的知识与技能。

我的长期兴趣是构建能够持续理解环境、主动学习并在真实世界中工作的 autonomous embodied agent。
