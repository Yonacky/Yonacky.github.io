Explorer

A persistent world model for embodied observers.

与其不断从最新一帧重新理解世界， Explorer 尝试维护一个持久、可解释并能够主动修正的内部世界状态。

Transport before dynamics.

当 observer 自身发生移动时， 首先根据自身运动对已有世界表征进行 transport， 然后才判断环境中哪些部分发生了真实变化。 高语义对象通过 registry 持久维护， 空间结构则由 structural map 组织。

A world model should not merely predict observations. It should maintain what the agent currently believes exists.

About

AUTONOMOUS AGENTS

我是一名人工智能专业学生， 当前主要关注 世界模型、表征学习、具身智能和自主学习系统 。

相比把智能理解为一个孤立的大模型， 我更感兴趣的是完整智能系统内部不同部分如何协同： 什么需要被感知，什么需要被保存， 什么可以预测，什么时候应该重新观察， 以及什么时候应该调用技能、工具或控制系统。

我的长期兴趣是构建能够 持续理解环境、主动获取知识并在物理世界中长期运行 的 autonomous embodied agent。
